# Lab02 Assignment – 23CSE301

This repository contains solutions for **Lab Session 02** using the dataset `Lab Session Data.xlsx`.

## 📂 Contents
- **A1_purchase.py** – Matrix rank and pseudo-inverse cost estimation  
- **A2_classify.py** – Customer classification (RICH/POOR)  
- **A3_stock.py** – Stock price mean, variance, probabilities, scatter plot  
- **A4_thyroid.py** – Thyroid dataset exploration (types, missing values, stats)  
- **A5_similarity.py** – Jaccard and Simple Matching Coefficient  
- **A6_cosine.py** – Cosine similarity calculation  
- **A7_heatmap.py** – Heatmap visualization of similarity measures  
- **A8_imputation.py** – Data imputation (mean, median, mode)  
- **A9_normalization.py** – Data normalization using Min-Max scaling
